# Components

This directory stores component manifests and, later, controlled component packaging metadata.

Each runtime component must declare its id, version, architecture, source, license, compatibility constraints and test status using `component.schema.json`.

Planned component groups include Wine, Box64/Box86, DXVK, VKD3D, renderers, rootfs/glibc, audio and compatibility utilities.

Binary files are not accepted without traceable metadata and license review.
